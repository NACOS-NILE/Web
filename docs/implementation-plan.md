# NACOS Nile — content completion and visual refinement plan

This plan was executed on the `submission/landing-page` branch. It keeps the independent Vercel site as a visual/content reference and uses the official NACOS repository for supplied branding, names, roles and assets.

## Sequence

1. Remove decorative section, discipline, program, portrait and menu numbering; replace the About “n + you” treatment with the supplied NACOS Nile logo and clear community line.
2. Add verified dues, shirt instalment, bank-transfer, Google Form and clearance guidance; keep payment confirmation outside the site.
3. Add two community-access routes, chapter email fallback and public social channels.
4. Extend executive records with the eight supplied LinkedIn URLs; omit a placeholder for Saidat Ahmed.
5. Add locally optimized dinner/workshop photography and an accessible gallery dialog with source provenance.
6. Turn the hero network into a restrained, upright-label orbital system with manual, hover/focus, off-screen, hidden-document and reduced-motion controls.
7. Refine program and discipline transitions, button states, gallery motion and responsive spacing.
8. Validate content, keyboard paths, clipboard fallback, anchors, responsive widths, reduced motion, static HTML, build, lint and production browser console.

## Acceptance criteria

- Official content remains factual and easy to understand; no invented figures, dates, deadlines, contacts, biographies or payment states.
- The hero communicates Learn · Build · Grow immediately, while the six disciplines remain readable and the explorer remains stationary.
- Payment and community actions are clear, secure and reversible; no personal data is collected by the site.
- Executive links have person-specific accessible names, visible focus and secure external-link attributes.
- The gallery supports keyboard and touch controls, captions, count, Escape dismissal and focus restoration.
- Motion is lightweight, pauses when appropriate and respects `prefers-reduced-motion`.
- Mobile, tablet, desktop and ultrawide layouts have no horizontal overflow, and core content is present without JavaScript.
